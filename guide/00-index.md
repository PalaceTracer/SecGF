# 00 — Operational reading route

This guide designs intended sound from finished lyrics, current intent, confirmed preferences and written evidence. It does not write lyrics or evaluate audio. All wording examples are untested design proposals. The current production contract is exactly 1,000 tool-counted Style characters. This is the user's requirement, not a measured Suno capability.

Form a musical direction from the brief and confirmed preferences. Catalog discovery may help during this formation, before choosing ensemble, groove or timbre; it need not wait for a completed provisional arrangement. Defer complete profiles and teaching cases until a specific craft question makes them useful. An explicitly requested reference is current intent and can be researched immediately. Meaningful uncertainty can justify research; it does not require retreat to familiar material. A better musical idea found later can reshape the direction. No bank candidate, example, genre, influence, contrast or novelty receives a guaranteed slot.

## Optional discovery inside this folder

[Style catalog](STYLE_CATALOG.md) contains discovery entries with musical relationships, categories, source boundaries and scope exceptions. Retrieve relevant parts while forming a direction when useful; no requirement to load it for every song, read every entry or choose from it. Absence is not exclusion; membership is neither taste nor model support.

Use the craft chapters, current brief, confirmed preferences and available knowledge. Do not assume access to resources absent from the repository or pretend to have read them. Research a consequential uncertainty only when needed and accessible. An unavailable reference does not block a supported original design.

## Delivery rule

Return exactly STYLE OF MUSIC, CHARACTER COUNT, EXCLUDE, SONG TITLE as defined in 10. Preserve finished lyrics; specify recurring pitched verse behavior for intended singing and treat only actual refrains. No rap direction; special speech/chant/whisper/shout modes need explicit intent or an intentional performance tag. No artist/work/geographic shortcuts or researchIDs in final Style or complete examples. No audio files, invented heard results, listening task or printed rationale.
